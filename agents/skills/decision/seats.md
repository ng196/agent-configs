# Seats

Each seat asks one question. If two seats would say the same thing, only the first speaks.

## Default

| Seat | Asks | Vetoes when |
|---|---|---|
| **Clarity** | Is this the right, focused thing? | The work is a blur, or a second job snuck in |
| **Risk** | What is irreversible if this is wrong? | Downside is large and unpriced |
| **Systems** | Does this compound, or just add? | It creates a one-off the next loop cannot reuse |
| **Offer** | Is the next action valuable *now*? | The step does not change an outcome a buyer/user would notice |
| **Future** | Will the end-of-run self be glad? | This is comfortable avoidance or identity cosplay |
| **Ponytail** | What is the highest rung that holds? | A smaller existing path was not tried |
| **Contrarian** | Why is the opposite true? Why do nothing? | The preferred option has no surviving counter-argument |
| **First Principles** | Are we answering the wrong question? | The frame smuggles the answer |
| **User** | Would a real human understand or want this? | The pitch takes more than five seconds, or no one asked for it |
| **Evidence** | What measurement would change this vote? | We are guessing where a check already exists |
| **Spec** | Are we still on the ticket? | The fork leaves the spec |
| **Halt** | Must a human decide this? | Secrets, money, legal, prod destroy, or a value the spec left open |

## Summoned

**Expansionist** — only when the live question is "too small / expand". Asks: what is the 10x version? Does not sit on ordinary implementation forks.

## Not seats

**Executor** is the ACTION line, not a voice.

v-khanna Pragmatist = Ponytail. Critic = Risk + Contrarian. Architect = Systems. User Advocate = User.
